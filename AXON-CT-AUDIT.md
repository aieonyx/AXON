### axon_crypto — P57.1 field and scalar operations

These functions are structurally constant-time:
no secret-dependent branches, `conditional_select` used for all secret choices.
`axon_ct_check` static analysis applies at HIR level.
LLVM attribute enforcement applies at codegen level.

| Function | Module | Status | Notes |
|---|---|---|---|

| `fe_sub` | `axon_crypto::field::fe_ops` | ✓ structural CT | `FOUR_P` addend, no branch |
| `fe_mul` | `axon_crypto::field::fe_ops` | ✓ structural CT | Schoolbook u128, no branch |
| `fe_square` | `axon_crypto::field::fe_ops` | ✓ structural CT | Symmetric mul, no branch |
| `fe_invert_fermat` | `axon_crypto::field::fe_ops` | ✓ structural CT | Addition chain, no secret branch |
